Privacy Policy – litreview.coach Uploader

1. Who is responsible

Aron Mußhoff, Lindenstr. 30, 54292 Trier, Germany. E-mail: lachomx@icloud.com. This policy covers the “litreview.coach Uploader”, an internal tool that publishes litreview.coach short videos to the litreview.coach YouTube channel. The general privacy policy for this website is here (German).

2. Use of YouTube API Services

The litreview.coach Uploader uses the YouTube API Services to upload videos. By using it, you agree to be bound by the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

3. Who uses the tool

The tool is not offered to the public. Its only user is the operator named above, who signs in with the Google account that owns the litreview.coach YouTube channel. No other people sign in, and no visitor data of this website is sent to YouTube by the tool.

4. What data the tool accesses, uses and stores

  • Permission requested: only the scope youtube.upload (upload videos to the signed-in channel). The tool cannot read, change or delete other videos, comments, analytics or account data.
  • Sign-in token: after Google sign-in, an OAuth refresh token is stored in a local, access-restricted file on the operator’s computer. It is never shared or uploaded anywhere else. No usernames or passwords are stored.
  • Upload data: the tool sends the video file, title, description, tags and visibility settings to YouTube. It keeps a local log with the video ID, link, upload time and visibility status, so the operator can see what was published.
  • The tool does not collect data from YouTube viewers, does not combine YouTube API data with other data and does not share any API data with third parties.

5. Deletion and revoking access

  • Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. The tool also has a built-in command that revokes the token at Google and deletes it locally.
  • When access is revoked, or if authorisation can no longer be verified, the stored token and all locally stored API data (video IDs and upload log) are deleted within 30 days.
  • Locally stored API data is not kept indefinitely: the tool automatically deletes upload log entries and video IDs older than 30 days.
  • To request deletion, e-mail lachomx@icloud.com. Requests are completed within 30 days.

6. Your rights

Under the GDPR you have the right to access, correct, delete and restrict processing of your data, the right to data portability and the right to object. You may also complain to a data protection supervisory authority, for example the Landesbeauftragte für den Datenschutz und die Informationsfreiheit Rheinland-Pfalz.
